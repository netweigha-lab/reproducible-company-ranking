# История изменений

## 1.1.0 — 2026-08-09

- в каталог рейтингов добавлен первый опубликованный выпуск — исследование компаний по продвижению в нейросетях 2026;
- добавлены отдельная карточка выпуска, строка реестра, ссылка на исследовательский репозиторий и обновлённые показатели каталога;
- основной текст рейтинга не дублируется на GitHub Pages: каталог выполняет навигационную функцию и ведёт на канонический исследовательский репозиторий;
- математическая методика базового сайта не изменялась.

## 1.0.1 — 2026-08-08

- каталог исходников `docs` получил собственную навигационную README-страницу;
- усилена ссылка из репозитория на каноническую GitHub Pages-версию;
- роли repository root, `/tree/main/docs` и Pages явно разделены для читателя;
- математическая методика и результаты контрольного расчёта не изменялись.

## 1.0.0 — 2026-08-08

- первый публичный выпуск Netweigha Lab;
- GitHub Pages назначен канонической читательской поверхностью;
- статус изменён на `PUBLISHED`, индексация разрешена;
- публичная лицензия на повторное использование не предоставляется;
- опубликован только состав `PUBLIC_RELEASE_MANIFEST.txt`.

## 0.5.0-local — 2026-08-08

- добавлена третья Pages-поверхность `ratings.html`: разводной каталог будущих рейтингов по пяти отраслевым кластерам, с нулевым честным реестром выпусков и publication-gate;
- добавлена самостоятельная визуальная система Netweigha Lab: оригинальный знак-граф, типографика, контрастная редакционная сетка и 3D-объект графа версий;
- GitHub обозначен вторичным текстовым маркером `× GITHUB` с пояснением «технологические решения на базе GitHub», без GitHub logo/Octocat и заявления о партнёрстве;
- выполнена очистка release-пакета: удалены тяжёлый неиспользуемый PNG-исходник героя и точный дубликат OG-файла, устранены мёртвые CSS-селекторы, manifest/schema/OG приведены к текущему знаку и палитре;
- общая базовая сетка трёх Pages-поверхностей вынесена в `assets/base.css`; доредизайновые inline-правила удалены, уникальные стили каталога вынесены в `assets/ratings.css`;
- страница `about.html` расширена до самостоятельной SEO/GEO-поверхности: identity, mission, research process, team functions, factoids, FAQ и согласованная schema.org-разметка;

- сформированы поисковые кластеры, prompt map и 18 допустимых фактоидов;
- title, description, OG и Article JSON-LD уточнены под основной интент;
- в первую публикацию добавлены определение, миссия и шесть функций команды;
- добавлены числовой паспорт метода, trust-вопросы и методологические источники;
- публичная граница `MATH_METHOD_ONLY` сохранена;
- публикация не выполнялась.
