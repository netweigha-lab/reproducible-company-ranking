# Политика confidence

`Confidence` показывает не качество сущности, а силу доказательного основания
конкретного значения. Шкала задаётся до расчёта и применяется одинаково ко
всем сущностям.

| Значение | Минимальное основание | Ограничение |
|---:|---|---|
| 1.00 | актуальный первичный источник, точная дата и полное поле | не означает безошибочность источника |
| 0.80 | первичный источник с явно описанным ограничением | ограничение должно быть сохранено |
| 0.60 | два согласующихся независимых вторичных источника | не заменяет первичный источник |
| 0.40 | один идентифицируемый вторичный источник | требует последующей проверки |
| 0.20 | фрагментарное или устаревшее основание | допустимо только как LIMITED |
| 0.00 | основание отсутствует | значение не участвует без отдельного правила |

Промежуточные значения допустимы только при документированном правиле. В
синтетическом примере confidence задан для проверки математики и не отражает
реальные источники.
