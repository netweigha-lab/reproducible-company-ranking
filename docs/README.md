# Сайт Netweigha Lab: методика рейтинга компаний

В этом каталоге находятся исходники опубликованного сайта Netweigha Lab.

**[Перейти к канонической читательской версии](https://netweigha-lab.github.io/reproducible-company-ranking/)**

Основная страница объясняет, как построить воспроизводимый рейтинг компаний:
как определить критерии и веса, нормализовать показатели, учитывать качество
доказательств, рассчитать Score и Uncertainty и проверить устойчивость результата.

## Страницы сайта

- [Методика рейтинга компаний](https://netweigha-lab.github.io/reproducible-company-ranking/) — основной исследовательский документ;
- [О лаборатории Netweigha Lab](https://netweigha-lab.github.io/reproducible-company-ranking/about.html) — миссия, предмет работы и функции исследовательской команды;
- [Каталог рейтингов](https://netweigha-lab.github.io/reproducible-company-ranking/ratings.html) — навигация по будущим отраслевым выпускам.

## Роль этого каталога

URL `/tree/main/docs` показывает структуру исходников GitHub Pages. Он нужен для
технической прозрачности, но не заменяет канонический документ. Актуальные
формулировки, визуальное представление и читательская навигация находятся на
GitHub Pages.
